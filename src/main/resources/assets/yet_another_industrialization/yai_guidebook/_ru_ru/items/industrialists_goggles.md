# Очки промышленника
###### *В моде летом 1766 года*

Наденьте их, чтобы видеть контуры многоблоков, не держа гаечный ключ в руке!

Отображение можно переключить в любой момент назначенной клавишей (по умолчанию: Numpad 3). **Если надеты выключенные очки, гаечный ключ в руке не включит отображение контуров!**
