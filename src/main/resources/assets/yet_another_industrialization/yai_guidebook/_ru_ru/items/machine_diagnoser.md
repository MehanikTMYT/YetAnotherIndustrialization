# Диагност машин
###### *По шестерёнке в день — и промышленник не нужен*

Нажмите ПКМ по машине, удерживая клавишу приседания, чтобы выявить распространённые неполадки, мешающие её работе.

Энергия не требуется! (возможно, на вашем этапе развития её ещё и нет...)
