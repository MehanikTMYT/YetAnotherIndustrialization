# Зарядник предметов
###### *"У нас дома уже есть Charge-O-Mat!" Charge-O-Mat дома:*

Заряжает помещённые в него предметы. В отличие от нажатия ПКМ по блокам хранения энергии, он передаёт энергию не мгновенно, поэтому предназначен для автоматизации, а не повседневной зарядки.
